# تطبيق مُلهم - توثيق الهيكلة البرمجية

## نظرة عامة

مُلهم هو تطبيق لياقة بدنية وتغذية ثنائي اللغة (عربي/إنجليزي) مبني بـ React Native (Expo). يوفر خطط تمارين مخصصة، متابعة التغذية، مدرب ذكاء اصطناعي، ومراقبة التقدم، متكامل مع Supabase لحفظ البيانات السحابية.

## طبقات الهيكلة

### 1. طبقة الخدمات (`services/`)

تتعامل مع جميع الاتصالات الخارجية:

- **`supabase.ts`** - تهيئة عميل Supabase مع AsyncStorage لحفظ الجلسة
- **`remoteRepo.ts`** - تنفيذ نمط المستودع لجميع عمليات Supabase. يتضمن منطق إعادة المحاولة للمرونة الشبكية

**الميزات الرئيسية:**
- إعادة محاولة تلقائية عند فشل الشبكة (حتى محاولتين)
- كشف أخطاء الشبكة وتغليفها
- دعم الإدراج الدفعي لمجموعات التمارين الكبيرة
- حل التعارضات لعمليات التحديث

### 2. طبقة الهوكات (`hooks/`)

المنطق التجاري المستخرج من المزودات:

- **`useFitnessCalculations.ts`** - يحتوي على جميع وظائف حسابات اللياقة:
  - `calculateBMR()` - معدل الأيض الأساسي (معادلة Mifflin-St Jeor)
  - `calculateTDEE()` - إجمالي الطاقة اليومية المصروفة
  - `getTargetCalories()` - السعرات المستهدفة حسب الهدف
  - `calculateMacros()` - توزيع الماكروز حسب نمط الحمية
  - `generateNutritionPlan()` - إنشاء خطة تغذية كاملة

### 3. طبقة المزودات (`providers/`)

مزودات سياق React للحالة المشتركة:

- **`AuthProvider`** - إدارة حالة المصادقة مع Supabase
- **`FitnessProvider`** - إدارة مركزية لجميع بيانات اللياقة مع استراتيجية تخزين مؤقت ثنائية الطبقة
- **`LanguageProvider`** - إدارة اختيار اللغة مع دعم RTL

### 4. طبقة الشاشات (`app/`)

مكونات شاشة خفيفة تجمع بين المزودات والهوكات والواجهة:
- الشاشات تتعامل مع التوجيه والتفاعلات والعرض
- المنطق التجاري مُفوّض للهوكات والمزودات
- الأنماط مُضمنة مع مكونات الشاشة

## تدفق البيانات

### تدفق المصادقة

```
شاشة الترحيب → اختيار اللغة → عرض الحساب
                                    ├── تسجيل الدخول → الصفحة الرئيسية
                                    ├── إنشاء حساب → تسجيل الدخول → الرئيسية
                                    └── تخطي → الإعداد → تبويب التمرين
```

### استراتيجية مزامنة البيانات

```
بدء التطبيق:
1. التحميل من AsyncStorage (فوري)
2. إذا كان المستخدم مسجلاً:
   أ. جلب من Supabase (في الخلفية)
   ب. دمج البيانات عن بُعد مع الذاكرة المؤقتة
   ج. رفع البيانات المحلية فقط إلى Supabase
3. إذا لم يكن هناك مستخدم:
   أ. استخدام الذاكرة المؤقتة المحلية فقط
```
