## 1. نظرة عامة

يوثق هذا المستند المراجعة النهائية التي أُجريت على تطبيق ملهم للياقة البدنية قبل تقديمه إلى متجر Apple App Store ومتجر Google Play Store. تشمل المراجعة جودة الكود، تدفق البيانات، تناسق واجهة المستخدم، معالجة الأخطاء، التوافق مع المنصات، والأمان.

## 2. هيكل التطبيق

### 2.1 هيكل الملفات

```
app/                          # توجيه الملفات عبر Expo Router
  (tabs)/                     # التنقل عبر التبويبات (4 تبويبات)
    _layout.tsx               # إعدادات شريط التبويبات
    plan.tsx                  # شاشة خطة التمارين
    nutrition.tsx             # التغذية وتخطيط الوجبات
    coach.tsx                 # المدرب الذكي
    profile.tsx               # الملف الشخصي والإعدادات
  auth/
    login.tsx                 # تسجيل الدخول بالبريد/كلمة المرور
    signup.tsx                # إنشاء حساب جديد
  _layout.tsx                 # التخطيط الجذري
  index.tsx                   # نقطة الدخول (منطق التوجيه)
  welcome.tsx                 # اختيار اللغة
  account-prompt.tsx          # خيار تسجيل الدخول/التخطي
  onboarding.tsx              # معالج إعداد الملف الشخصي
  workout-details.tsx         # شاشة تنفيذ التمرين
  meal-details.tsx            # تفاصيل الوجبة وتعديلها
  bioinformatics.tsx          # التخصيص الجيني (قائمة الانتظار)
providers/
  AuthProvider.tsx            # مصادقة Supabase
  FitnessProvider.tsx         # إدارة الحالة المركزية
  LanguageProvider.tsx         # دعم اللغات (عربي/إنجليزي)
services/
  remoteRepo.ts              # طبقة بيانات Supabase
  supabase.ts                # إعدادات عميل Supabase
hooks/
  useFitnessCalculations.ts  # حسابات BMR، TDEE، الماكروز
constants/
  colors.ts                  # رموز التصميم
  translations.ts            # الترجمات العربية والإنجليزية
data/
  exercises.ts               # قاعدة بيانات التمارين
  meals.ts                   # قاعدة بيانات الوجبات السعودية
types/
  fitness.ts                 # تعريفات أنواع TypeScript
```

### 2.2 التقنيات المستخدمة

| الطبقة | التقنية |
|--------|---------|
| الإطار | React Native 0.81.5 + Expo SDK 54 |
| التنقل | Expo Router (قائم على الملفات) |
| إدارة الحالة | @nkzw/create-context-hook + AsyncStorage |
| الخادم الخلفي | Supabase (المصادقة + PostgreSQL) |
| ميزات الذكاء الاصطناعي | @rork-ai/toolkit-sdk |
| التنسيق | React Native StyleSheet |
| اللغة | TypeScript (صارم) |

## 4. مراجعة الشاشات

### 4.1 شاشة الترحيب (`welcome.tsx`)
- **الحالة**: ناجح
- اختيار اللغة (عربي/إنجليزي) يعمل بشكل صحيح
- رسوم متحركة عند الدخول
- حفظ اختيار اللغة في AsyncStorage

### 4.2 خيار الحساب (`account-prompt.tsx`)
- **الحالة**: ناجح
- يعرض خيار تسجيل الدخول وخيار التخطي
- التخطي ينقل إلى صفحة إعداد الملف الشخصي
- تسجيل الدخول ينقل إلى شاشة المصادقة

### 4.3 تسجيل الدخول والتسجيل (`auth/login.tsx`, `auth/signup.tsx`)
- **الحالة**: ناجح
- مصادقة البريد/كلمة المرور عبر Supabase
- معالجة الأخطاء لبيانات الاعتماد غير الصحيحة
- اكتشاف الحسابات المكررة عند التسجيل
- حالات التحميل أثناء استدعاءات API

### 4.4 إعداد الملف الشخصي (`onboarding.tsx`)
- **الحالة**: ناجح
- معالج من 7 خطوات: العمر، القياسات، الجنس، الهدف، النشاط، الموقع، الجدول
- التحقق من المدخلات في كل خطوة
- شريط تقدم
- حفظ الملف الشخصي في AsyncStorage و Supabase

### 4.5 خطة التمارين (`(tabs)/plan.tsx`)
- **الحالة**: ناجح
- إنشاء تلقائي لخطة أسبوعية بناءً على الملف الشخصي
- تصفية التمارين حسب الموقع (صالة/منزل/معدات بسيطة)
- تصفية التمارين حسب الإصابات
- تعديلات بناءً على الهدف (مجموعات، تكرارات، راحة)
- تمارين إحماء وتهدئة مضمنة
- تتبع إكمال التمارين ومزامنتها مع Supabase
- تعديل التمارين (مجموعات، تكرارات، راحة، وزن)
- إضافة/إزالة التمارين من الجلسات
- دعم التمارين المفضلة
- إعادة توليد الجلسات

### 4.6 التغذية (`(tabs)/nutrition.tsx`)
- **الحالة**: ناجح
- تقييم غذائي من 3 خطوات
- إنشاء خطة وجبات أسبوعية بناءً على الوجبات السعودية
- تحجيم السعرات حسب الهدف
- تتبع إكمال الوجبات
- إنشاء قائمة مشتريات من خطة الوجبات
- إنشاء وجبات مخصصة عبر الذكاء الاصطناعي

### 4.7 المدرب الذكي (`(tabs)/coach.tsx`)
- **الحالة**: ناجح
- محادثة ذكية مع أدوات متعددة
- اقتراح تمارين وحفظها
- اقتراح وجبات وحفظها
- تحليل التقدم
- أزرار إجراءات سريعة

### 4.8 الملف الشخصي (`(tabs)/profile.tsx`)
- **الحالة**: ناجح
- تتبع الوزن مع سجل التقدم
- عرض BMI، BMR، TDEE، السعرات المستهدفة
- تعديل الملف الشخصي
- تبديل اللغة
- تسجيل الخروج
- عرض النشاط الأخير

### 4.9 تفاصيل التمرين (`workout-details.tsx`)
- **الحالة**: ناجح
- عرض تمرين بتمرين
- تتبع الإكمال لكل تمرين
- روابط فيديو لكل تمرين
- عرض المعدات
- شريط التقدم

### 4.10 تفاصيل الوجبة (`meal-details.tsx`)
- **الحالة**: ناجح
- عرض المعلومات الغذائية
- قائمة المكونات مع تبديل الوزن/الحجم

- إضافة/إزالة المكونات
- معالجة شاملة لأخطاء تحليل JSON

## 5. مراجعة تدفق البيانات

### 5.1 تدفق المصادقة
```
الترحيب -> اختيار اللغة -> خيار الحساب -> تسجيل الدخول/التسجيل -> مصادقة Supabase
                                          -> تخطي -> إعداد الملف (وضع الضيف)
```

### 5.2 استراتيجية مزامنة البيانات
- **المحلي أولاً**: جميع البيانات مخزنة مؤقتاً في AsyncStorage
- **مزامنة عن بعد**: Supabase للمستخدمين المصادقين
- **مقاومة عدم الاتصال**: التطبيق يعمل بالبيانات المخزنة عند عدم توفر الشبكة
- **حل التعارضات**: البيانات البعيدة لها الأولوية عند التحميل
- **الدفع عند الفجوة**: البيانات المحلية تُدفع إلى Supabase إذا كان البعيد فارغاً

### 5.3 معالجة الأخطاء
- أخطاء الشبكة تُلتقط وتُغلف كـ `NETWORK_ERROR`
- منطق إعادة المحاولة (محاولتان مع تأخير تصاعدي)
- تراجع سلس إلى البيانات المخزنة عند الفشل
- رسائل خطأ واضحة للمستخدم عبر Alert

## 7. التوافق مع المنصات

### 7.1 iOS
- معالجة المنطقة الآمنة عبر `react-native-safe-area-context`
- سلوك تجنب لوحة المفاتيح مُهيأ لـ iOS
- لا توجد وحدات أصلية خارج توافق Expo Go

### 7.2 Android
- سلوك تجنب لوحة المفاتيح مُهيأ لـ Android
- أيقونة التكيف مُهيأة في `app.json`
- اسم الحزمة: `app.rork.mulhim_app_clone`

### 7.3 الويب
- جميع عمليات Supabase تعمل على الويب
- Alert مُجهز للويب
- AsyncStorage مُجهز (localStorage)
- SafeAreaView يعمل على الويب

## 8. اعتبارات الأداء

- التحميل الكسول عبر Expo Router
- قاعدة بيانات التمارين محملة ثابتاً (بدون استدعاء شبكة)
- قاعدة بيانات الوجبات محملة ثابتاً
- استعلامات Supabase مُجمعة حيثما أمكن (Promise.all)

## 9. توصيات للإصدارات المستقبلية

1. **الإشعارات**: إضافة تذكيرات التمارين وتتبع الوجبات
2. **قائمة انتظار غير متصلة**: تخزين التغييرات عند عدم الاتصال ومزامنتها لاحقاً
3. **دعم الصور**: إضافة صور/GIF توضيحية للتمارين
4. **ميزات اجتماعية**: مشاركة التقدم مع الأصدقاء
5. **Apple Health / Google Fit**: التكامل مع منصات الصحة
6. **الوضع الداكن**: إضافة دعم تبديل السمة
7. **ترحيل React Query**: الانتقال من جلب البيانات اليدوي إلى React Query

## 10. الخلاصة

تمت مراجعة تطبيق ملهم بشكل شامل وتم حل جميع المشاكل المكتشفة. التطبيق مكتمل وظيفياً مع:
- 4 تبويبات رئيسية (الخطة، التغذية، المدرب، الملف الشخصي)
- تدفق مصادقة كامل مع وضع الضيف
- دعم ثنائي اللغة (عربي/إنجليزي)
- تكامل Supabase لاستمرار البيانات
- ميزات التدريب المدعومة بالذكاء الاصطناعي
- معالجة شاملة للأخطاء ومقاومة عدم الاتصال

التطبيق جاهز للتقديم إلى كل من Apple App Store و Google Play Store.
